# 设备分析 — 下一阶段聚焦（核心机深度）

> 状态：方向已定 · 最后更新：2026-09-11  
> 关联：[角色计划](./equipment-analysis-role-plan.md) · [产品规格](./equipment-analysis-product.md)  
> 现场结论：**只有大的、贵的、核心设备上分析**；台数少，但**深度必须够**。Demo 只做 **3 台**差异化设备。

---

## 1. 判断（相对上一阶段的转向）

| 之前 | 现在 |
|------|------|
| 全厂广铺：上千台、舰队 KPI、多类型一锅端 | **核心机深挖**：现场约 12 台离心机级核心设备，Demo 3 台 |
| 舰队页卖「先管谁」为主 | 舰队页**瘦身**，单机页卖「为什么 / 依据够不够」 |
| 指标偏摘要（HI、风险%、能耗分） | **多图深度**：频谱、特征频段、瀑布图、测点簇趋势 |

上一阶段（F1～F9）决策闭环仍保留：结论卡、停机时长、调优分流。  
下一阶段不是再加门户，而是把**单机现状 / 未来**做成「分析到位」的证据墙。

刻意不做：集团驾驶舱、全厂千台灌水、所有机型示意铺开、金额 ROI。

## 2. 信息架构（不拆站，改重心）

```text
侧栏（轻）                              单机（重）
  设备列表（3 台入口）                    概况（身份）
  全局现状（本班优先，别堆图）              现状 ★ 深度证据主场
  全局风险（谁该排窗口）                   未来 · 决策 + 结构示意
  运行调优（策略分流）                     调优 · 参数对照
```

层级改为：**列表选核心机 → 单机把分析做透**。  
全局页只回答优先级；**图表预算优先砸在单机现状**。

---

## 3. 单机「现状」深度图墙（建议顺序）

结论卡仍置顶。其下按「从易读到深」排布，异常机默认多展开，正常机可折叠。

| # | 区块 | 图表 / 表 | 作用 |
|---|------|-----------|------|
| 1 | 结论与动作 | 结论卡 + 建议步骤 | 先说人话 |
| 2 | 工况趋势 | 振动 / 温度 / 电流 / 功率 多线 + 正常带 | 已经偏了多久 |
| 3 | **诊断依据 · 频谱** | 2D 频谱折线（径向垂直等） | PMA「波形参考」 |
| 4 | **特征频段表** | 实际值 / 预警阈值 / 状态 | 哪条故障特征越限（如不对中 2×） |
| 5 | **瀑布 / 时频面** | 3D 或伪彩：频率 × 时间 × 幅值 | 峰是否随时间抬升 |
| 6 | 多源一致性 | 振动+温升+电流同向 | 提高置信 |
| 7 | 时间线 | 告警→诊断→动作 | 班组可执行 |

**边界**

- **频谱 + 特征表 + 瀑布图** → 只放 **现状 Tab**（诊断证据）  
- **结构示意热区** → 仍放 **未来 Tab**（部件定位 + 决策）  
- **全局页** → 不再堆频谱/瀑布；最多链到单机「诊断依据」
