# 排产进阶计划：替换 Excel

> 目标：比 Excel「改格子」更好用——**先算影响再落盘、负荷看得见、越用越准、可试排不污染正式计划**。  
> 日期：2026-09-21

---

## 现状（已具备）

- 工单拆分：预计天数 × 每天人数
- 甘特自动排期派人；缺编空岗 + 冲突标注
- 请假 / 替班台账
- 报工开工 / 暂停 / 完工回写

## 本期要做（按优先级）

| # | 能力 | 对照 Excel | 验收 |
|---|------|-----------|------|
| 1 | **插单 / 改期影响预览** | 改完才发现撞车 | 拖拽、改工序、从工单排产、一键重排前先看影响，确认后才写入 |
| 2 | **人员负荷热力图** | 透视表手搓且不联动 | 甘特页按人×日看占用；超载标红 |
| 3 | **报工校准标准工时** | 实际从不回写模板 | 完工后累计实际耗时，模板给出建议天数 |
| 4 | **What-if 试排沙盘** | 另存一堆文件 | 进入试排可乱改；放弃还原 / 发布成正式 |

## 不做（本期）

- 多工厂、精确成本、复杂班次拆分
- 销售端「可承诺交期」独立门户（可作下期）
- 原生 App；本期仍用网页报工

## 下期候选

- 交期承诺试算、异常事件一键顺延、移动端极简报工、审计回放增强

---

实施顺序：1 → 2 → 3 → 4，全部落地后在甘特页可演示「比 Excel 强」的完整闭环。
