## 1. 目标

单机「未来」分析中增加 **整机横向剖视示意 + 可点热区**：

- 预测/归因命中的部件 **标红**，关注 **标橙**，已覆盖正常 **灰实**，未启用 **灰虚**
- 点击热区 → 旁侧展示部件名、贡献度、关联测点、建议动作
- 与 `attribution_top3` / `likely_fault` / `primary_cause` / 故障覆盖墙 **同源**

## 3. 共用颜色规则

| 色 | 含义 | Demo 触发 |
|----|------|-----------|
| **红** | 本次命中 / 高风险 | 归因 Top1，或贡献 ≥35%，或告警级且关键词命中 |
| **橙** | 关注 / 劣化中 | 归因 Top2～3，或贡献 15%～34%，或预警级命中 |
| **灰（实）** | 正常且模型已覆盖 | 有测点映射，当前无异常 |
| **灰虚** | 未启用 / 无模型 | 无测点或未进模型 |

**冲突时只保留一个红核心件**，避免满屏红：螺杆优先轴承/振动 → 排气温度 → 油路 → 电机。

## 8. 与 API 映射

1. 有 `attribution_top3`：`metric` / `name` / `text` 模糊匹配热区 → Top1 红，Top2～3 橙。  
2. 仅有 `likely_fault` / `primary_cause`：关键词落到默认热区。  
3. `alert_level=alarm` 且无法细分：只红该机型「核心件」（螺杆=`sc_bearing`，泵=`pump_bearing`，冷机=`ch_compressor`）。  
4. 其余已定义热区 → 灰实；预留未映射 → 灰虚（本 Demo 三类均定义为已覆盖）。

前端实现：`frontend/src/pages/equipment-analysis/schematics/`。
