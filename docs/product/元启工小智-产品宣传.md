# 元启·工小智

**工业现场的智能作业平台**

> 一句话定位：把「排得清、诊得准、检得稳、方得优、艺得精、规得住」做成可分可合的能力域，按工厂真实节奏上线，而不是一次性堆一个大系统。

---

## 1. 我们解决什么

制造企业并不缺系统，缺的是**能跟着车间走的决策闭环**：

| 现场常见困境 | 后果 |
|--------------|------|
| 交期靠人脑、插单靠吼 | 计划一改全乱，争机、抢人、加班却仍延误 |
| 设备「坏了才知道」 | 非计划停机、备件被动、产能承诺失信 |
| 质检在事后、标准在纸上 | 批次风险后置，经验难以复制 |
| 配方与工艺靠老师傅 | 换人就波动，优化难沉淀、难复用 |
| 操作规范难落地 | 培训成本高，同类失误反复发生 |

**元启·工小智**面向离散制造与动力/公用工程并存的工厂，以**平台壳 + 可售业务模块**交付：可先解决最痛的一块，再按价值叠加，最终形成「计划—设备—质量—工艺—规范」一体的工业智能作业能力。

### 2.2 售卖原则

- **可分**：任一能力域可单独采购、单独上线、单独授权。
- **可合**：多模块共用同一平台壳、同一组织与账号体系；合买强调**数据对齐与业务闭环**，而非功能堆砌。
- **可演进**：按痛点分期开通——交期、设备、质量、配方、工艺、规范，节奏由工厂决定。
- **平台壳不单卖**：登录、组织、权限、租户 SKU、审计等为各模块共用底座，随业务模块交付。

## 4. 智排 · 智能排产模块（已上线）

### 4.1 定位

**把交期、人、机、班次一次排清：插单可试、冲突可分、现场可报。**

面向多品种、小批量、多班制、设备争用明显的车间，解决「Excel 排程改不动、通用排程不懂车间规则」的问题。

### 4.2 谁用

| 角色 | 典型动作 |
|------|----------|
| 计划 / 排产员 | 维护主数据、工单展开、自动排产与重排 |
| 班组长 / 调度 | 甘特微调、处理冲突、试排确认后发布 |
| 现场班组 | 工序报工、电子签名、反馈偏差 |
| 生产主管 | 看交期桶、人机负荷、冲突与延误风险 |

### 4.3 能力闭环

```
基础数据 → 工单管理 → 排产甘特 → 工序报工
   │            │           │           │
 班制/班组    优先级/     拖拽调整     开工暂停完工
 技能/设备    插单/返工   试排沙箱     日报与签名
 人员/模板    工序展开    冲突与负荷   计划-实绩偏差
 排班周历                多策略重排
```

**主数据分层（核心差异）**

| 层级 | 管什么 | 不管什么 |
|------|--------|----------|
| 排班周历 | 人是否到岗（白/中/夜、请假、替班） | 不在周历里指定机台 |
| 工序模板 | 技能要求 + **可用设备池** | 不在模板阶段锁死某一台 |
| 甘特排产 | 日期、班次、责任人、**具体机台** | — |
| 冲突引擎 | 时间重叠上的人/机互斥与班次负荷 | — |

**冲突规则贴近车间习惯**

- **硬冲突**：例如两人抢同一机、无法证明可串行 → 明确标红，发布与 digest 可感知。
- **超载告警**：同人同机同班多单按日累加工时超过标准班次 → 告警，允许保存与继续调整（符合「同班串行」现实）。
- **请假仍派工 / 缺编 / 技能不符 / 延期** 等风险分档，避免「一律红灯」或「一律不管」。
- 已选定具体设备时，**不以班组互斥误杀**多机班组的合理并行。

**计划侧智能**

- 自动排产 / 重排策略：保交期、级别优先、交期优先等。
- **试排沙箱**：进入试排 → 看影响预览 → 发布或放弃，插单不再「改死了回不去」。
- 设备池未选手动时，可按当日该班次**负荷最低的启用设备**自动落机。
- 今天以前可冻结，避免历史计划被重排打乱。

**现场闭环**

- 按工作日报工：开工 / 暂停 / 完工。
- 日报与**电子签名**，责任可追溯。
- 计划与实绩偏差可处置（独立权限），形成改进输入，而不是只留一张甘特图。

### 4.4 单买智排即可交付的价值

- **不依赖**工诊或 IoT：仅凭计划占用 + 报工，即可表达设备「在跑 / 空闲」（空闲 ≈ 启用且该时段无计划占用）。
- 适合「先把交期与争用管住」的工厂，作为工小智的第一块落子。

### 4.5 与常见做法的差异

| 维度 | Excel / 口头调度 | 通用排程套件 | **智排** |
|------|------------------|--------------|----------|
| 人机关系 | 混在一张表 | 常偏算法黑盒 | **人—技能设备池—落机**分层清晰 |
| 冲突 | 事后发现 | 易一刀切卡死 | **硬冲突 / 超载分档** |
| 插单 | 全表重算 | 改完难回退 | **试排 + 影响预览 + 发布** |
| 现场 | 另找工具 | 常弱 | **报工签字 + 偏差处置** 同体系 |

### 4.6 适用企业（自检）

- 三班倒或多班制，请假替班频繁  
- 关键设备（焊机、机加、注塑等）争用明显  
- 插单、返工、返修多，交期压力大  
- 计划与现场之间需要可追溯的报工闭环

## 5. 工诊 · 设备健康分析模块（已上线）

### 5.1 定位

**先看清坏在哪，再看会不会坏，最后在安全边界内把设备用好。**

面向设备、维修、能源与工艺相关岗位，解决「只有告警列表、没有证据与处置路径」的问题。覆盖生产机台与动力公用设备（如空压、泵、冷水机组等场景）。

### 5.2 谁用

| 角色 | 典型动作 |
|------|----------|
| 设备 / 维修工程师 | 诊断总览、单机对照分析、事件处置 |
| 能源 / 运行岗 | 运行优化建议、负荷与约束检查 |
| 车间主管 | 机队健康分布、未来风险、部门范围对比 |
| 信息化 / 采集配置 | 数据源与测点绑定、组织范围筛选 |

### 5.3 能力闭环

```
采集配置 → 设备列表 / 机队视图 → 分析诊断总览 → 单机深潜
                                    │
                    现状健康 │ 未来风险 │ 事件队列（分口径）
                                    │
              对照分析 → 预测(RUL等) → 运行优化（带约束）
```

**机队视角**

- 按部门 / 设备类型 / 运行或在线状态 / 时间口径（本班、24h、7d 等）看全局。
- KPI：总数、在线、异常与关注、**未来风险**、待处理事件。
- **现状健康分布**与**未来风险**同屏展示、**分口径阅读**，避免揉成一个「红黄绿」糊弄决策。
- 趋势、类型分布、组织分布等机队图表，服务「先圈范围、再下钻」。

**单机深潜（证据链，而不只是告警）**

- **对照分析**：结论、证据、原因概率、恶化情景、趋势与测点、多源一致、同业对比、处置步骤。
- **未来**：多时间窗风险、RUL 及置信、故障类型概率、预案 / 备件 / 工单提示；离线则预测暂停，避免假精确。
- **健康示意**：关键部位热区可点选，辅助沟通与培训。
- **运行优化**：节能、平衡、高负荷、长寿命等场景；**报警未关闭时可阻断激进调优**，先处置再优化。

**设备对比**

- 多设备、多周期横向对照（含状态泳道等），适合同型机或跨班组对比。

### 5.4 单买工诊即可交付的价值

- 不依赖智排即可独立建设采集—诊断—预测—优化链路。
- 与工厂组织树同源过滤，适合多车间、多工厂按范围看机队，而不是静态 Demo 列表。

### 5.5 与常见做法的差异

| 维度 | 纯 SCADA / 告警台 | 通用 BI 看板 | **工诊** |
|------|-------------------|--------------|----------|
| 输出 | 阈值超限 | 指标好看 | **证据 → 对照 → 处置** |
| 时间 | 多为现状 | 事后统计 | **现状与未来分口径** |
| 优化 | 少或无约束 | 难落地 | **带状态约束的调优建议** |
| 组织 | 点位扁平 | 报表割裂 | **机队范围 + 单机钻取** 一体 |

### 5.6 适用企业（自检）

- 关键设备停机损失高，备件与维修被动  
- 动力站与产线设备并存，需要机队级视野  
- 已有或计划接入 PLC / 电气 / 环境等测点  
- 希望从「看报警」升级到「可解释诊断 + 可约束优化」

## 6. 智排 × 工诊：合买与升级路径

两模块**边界清晰、数据可对齐**：

| | 智排 | 工诊 |
|--|------|------|
| 管什么 | 计划资源、占用、派工与报工 | 采集、健康、预测与优化 |
| 设备对象 | 计划台账与甘特落机 | 现场设备与测点 |
| 合买增强 | 通过**设备编码映射**对齐「计划机台 ↔ 现场机台」 | 不把诊断算法塞进甘特 |

**合买对企业的增量价值**

1. **敢排**：关键机健康与风险可见，高风险机避免仍被高负荷占用。  
2. **敢养**：维修窗口可对照交期与班次，减少「修了却耽误单」或「为了交期硬扛到坏」。  
3. **对齐决策**：同一台设备，甘特上是产能，诊断上是风险——两边对得上，排产与维修会议用同一套事实。

**推荐落地节奏**

```
阶段一：交期与设备 —— 智排 + 工诊
阶段二：质量与工艺 —— 智检 + 智方 / 智艺
阶段三：现场规范 —— 智规与各生产模块动作绑定
```

## 7. 智检 · 工业质检模块（可售）

> **合同物料名**：工业质检模块（智检）

### 7.1 定位

**把质量从事后判废，前移到过程可检、结果可追溯、异常可闭环。**

### 7.2 能力要点

- 过程检、成品检、抽样与全检策略；按工序 / 批次挂接工单  
- **不合格闭环**：隔离、让步、返工、报废可配置，责任可追溯  
- 检验记录、影像 / 数据证据与质量报告归档  
- 质量看板：不良分布、逃逸风险、供应商 / 班组对比  
- 可单买；与智排合买时，质检结果驱动放行与返工重排  

### 7.3 与常见做法的差异

| 维度 | 常见做法 | 智检 |
|------|----------|------|
| 时机 | 事后抽检 | 过程 + 成品闭环 |
| 追溯 | 纸质 / 分散表 | 批次证据一体 |
| 处置 | 口头协商 | 可配置闭环 |

### 7.4 衔接口

| 衔接 | 意图 |
|------|------|
| → 智排 | 质检结果影响放行、返工工单与交期重排 |
| → 工诊 | 质量异常与设备健康 / 工况对照 |
| → 智艺 / 智方 | 质检反馈进入工艺与配方优化闭环 |
| → 智规 | 检验作业纳入规范与执行记录 |

## 8. 智方 · 配方优化模块（可售）

> **合同物料名**：配方优化模块（智方）

### 8.1 定位

**在成本、质量与供应约束下，把配方从老师傅经验变成可复制、可审计的资产。**

### 8.2 能力要点

- 配方主数据与版本管理：草稿、试验、量产、冻结可区分  
- 目标与约束可配置（成本、性能、稳定性、关键原料可用性等）  
- **可解释优化建议**：给出调整方向与预期影响，便于评审签核  
- 试验批结果回写，驱动下一轮配方迭代  
- 可单买；与智检 / 智艺合买时形成「方—检—艺」闭环  

### 8.3 与常见做法的差异

| 维度 | 常见做法 | 智方 |
|------|----------|------|
| 沉淀 | 个人经验 | 版本化资产 |
| 优化 | 试错靠感觉 | 约束下可解释 |
| 切换 | 口头通知 | 签核后量产切换 |

### 8.4 衔接口

| 衔接 | 意图 |
|------|------|
| → 智艺 | 配方变更驱动工艺窗口调整 |
| → 智检 | 用实测质量验证配方效果 |
| → 智排 | 换方 / 换批对产能与交期的影响可见 |

## 9. 智艺 · 工艺优化模块（可售）

> **合同物料名**：工艺优化模块（智艺）

### 9.1 定位

**盯住关键工序的工艺窗口与节拍稳定性，减少「同设备、不同人、不同结果」。**

### 9.2 能力要点

- 关键工序工艺参数采集与对照，建立黄金批次基线  
- **工艺窗口推荐**：在质量与节拍约束下给出可执行参数带  
- 过程偏移预警：偏离窗口及时提示，避免大批量不良  
- 与设备工况、质检结果联合分析，区分「机」与「艺」问题  
- 可单买；与智排合买时，节拍变化可反馈标准工时  

### 9.3 与常见做法的差异

| 维度 | 常见做法 | 智艺 |
|------|----------|------|
| 标准 | 口头传艺 | 窗口 + 基线 |
| 波动 | 事后复盘 | 偏移即时预警 |
| 归因 | 人机混谈 | 可联合设备 / 质检 |

### 9.4 衔接口

| 衔接 | 意图 |
|------|------|
| → 工诊 | 工艺异常是否由设备劣化引起 |
| → 智检 | 工艺偏移与不良模式对应 |
| → 智排 | 工艺节拍变化反馈到标准工时与排程 |
| → 智规 | 优化后的参数写入标准化作业 |

## 10. 智规 · 操作流程规范模块（可售）

> **合同物料名**：操作流程规范模块（智规）  
> 对外统一称 **智规**（对内可称工规）。

### 10.1 定位

**把 SOP 从墙上的文件，变成可执行、可培训、可检查、可追溯的现场动作。**

### 10.2 能力要点

- 覆盖开班、换型、点检、保养、安全等高频作业规范  
- **步骤级执行**：关键点确认、拍照 / 签字、偏离记录  
- 版本生效与回收：现场只看见当前有效版本  
- 培训考核与执行合规分析，同类失误可定位到步骤  
- 可单买；与智排 / 工诊合买时，派工与点检动作绑定规范  

### 10.3 与常见做法的差异

| 维度 | 常见做法 | 智规 |
|------|----------|------|
| 载体 | 纸质 / PDF | 可执行流程 |
| 执行 | 靠自觉 | 步骤确认可追溯 |
| 改进 | 难定位 | 偏离到步骤 |

### 10.4 衔接口

| 衔接 | 意图 |
|------|------|
| → 智排 | 开班、换型、特殊工序与排班 / 派工绑定 |
| → 工诊 | 点检 / 保养规范与健康事件闭环 |
| → 智检 | 检验作业规范化 |
| → 智方 / 智艺 | 配方与工艺变更强制带规范更新 |
