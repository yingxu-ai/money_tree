# 工视 · 多维生产分析 v1 规格

> 高级付费 SKU：`progress-analytics`  
> 目标：通用分析引擎（筛选 + 分组 + 指标 + 下钻），不堆固定报表。  
> 技术栈：现有 React + Ant Design + ECharts；后端 FastAPI；数据先用已确认报工逻辑事实。

---

## 1. 定位与边界

| 项 | 约定 |
|----|------|
| 菜单 | 生产进度下「多维分析」（需开通高级 SKU） |
| 路由 | `/progress-analytics` |
| API | `/progress-analytics/*`（与基础生产进度路径隔离，便于 SKU 门禁） |
| 与「进度分析」 | 进度分析=订单上下文固定切片；本模块=任意组合全局探索 |
| 未开通 | 菜单裁剪；API 403 |

**非目标（v1）**：小时维、工厂/车间树、等待/停机实采、AI 诊断、ClickHouse。

## 2. 数据模型（逻辑）

### 2.1 事实行（来源：已确认 `shop_floor_reports`）

一条事实 ≈ 一人 × 归属日 × 工序 ×（工单或产品）× 可选设备：

| 逻辑字段 | 来源 |
|----------|------|
| work_date | `work_date`（班次归属日） |
| shift_family_id / shift_name | 排班或报工快照 |
| person_id / person_name | 作业人 |
| team_id / team_name | 人员所属班组 `resource_id` |
| equipment_id / equipment_name | 设备 |
| process_name | 工序名 |
| work_order_id / label | 工单 |
| order_id | 订单 |
| product | 产品 |
| output_qty | `qty` |
| production_hours | `hours` 或起止折算 |

仅 **`status=confirmed`** 进入分析。

### 2.2 维度白名单（v1）

`work_date` | `shift` | `team` | `person` | `equipment` | `process` | `work_order` | `product` | `order`

### 2.3 指标白名单（v1）

| 编码 | 名称 | 计算 | 聚合 |
|------|------|------|------|
| output_qty | 总产量 | SUM(qty) | SUM |
| production_hours | 生产工时 | SUM(hours) | SUM |
| hourly_output | 小时产量 | SUM(qty)/SUM(hours) | **比值（禁止对各组小时产量平均）** |
| unit_time | 单位耗时(小时/件) | SUM(hours)/SUM(qty) | 比值 |
| unit_minutes | 单位耗时(分钟/件) | unit_time×60 | 比值 |
| achieve_pct | 效率达成率% | 标准分钟÷实际分钟×100 | 比值；无标准则空 |

标准耗时：工序主数据 `unit_minutes`（按工序名匹配）。

## 3. 通用查询 API

`POST /progress-analytics/query`

```json
{
  "date_from": "2026-10-01",
  "date_to": "2026-11-05",
  "filters": {
    "team_ids": [],
    "person_ids": [],
    "equipment_ids": [],
    "process_names": [],
    "work_order_ids": [],
    "products": [],
    "order_ids": [],
    "shift_family_ids": []
  },
  "group_by": ["team", "process"],
  "metrics": ["output_qty", "production_hours", "hourly_output", "unit_minutes", "achieve_pct"],
  "sort": { "field": "hourly_output", "order": "desc" },
  "limit": 200
}
```

约束：`group_by` 1～3 个；`limit`≤500；维度/指标白名单校验。

另：`GET /progress-analytics/meta` 返回可用维度、指标、筛选项。

## 4. 前端工作台

- 顶：时间快捷 + 范围 + 筛选  
- 中：分组维度（最多 3）+ 指标 + 图表类型  
- 主区：图 + 表；行点击 → 将该行值写入 filters 并可选下钻下一维  
- 面包屑：当前切片路径
