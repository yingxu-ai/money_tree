## 统一的是版式，不是内容

统一：

- 首屏框架、章节顺序、卡片 / 时间线 / 对比表组件
- 字号、间距、圆角、按钮、打印分页和页脚
- 每个模块一个强调色：青 / 蓝 / 绿 / 琥珀 / 紫 / 灰
- 页面不依赖外部字体和图片，断网 / 内网也能打开

刻意不统一：

- 首屏“谁最该看”和第二个按钮，按模块换
- 03 节有一个模块专属证据块：试排影响清单 / 告警对照 / 批次证据包 / 版本状态机 / 窗口三问 / 步骤证据
- 05 节有模块专属“上线门槛”，不是同一套 5+5 清单
- 06 节是模块专属试点动作，不是同一套“30 分钟看现状”
- 07 节只保留 6 个问题，前 4 个按模块写
- 联系页写清“你会拿到什么”，每个模块不同

## 上线前替换

1. **联系方式**：每页 `#contact` 里的姓名、手机、微信、邮箱
2. **二维码**：把 `.qr` 占位替换成销售微信二维码；打印默认隐藏，如需印在封底，把 `_customer.css` 打印段的 `.qr{display:none}` 去掉
3. **价格口径**：把“怎么报价”一段换成公司实际说法
4. **示例数据**：场景里的时间、批次号、百分比、撞机数均为示例，建议换成试点数据
5. **终端说明**：智排页写了“手机端暂未适配，现场建议车间电脑 / 平板”；如产品已支持手机报工，请改掉
6. **部署 / 服务**：按实际合同范围核对“云端 / 本地”“上线培训 + 使用答疑”
7. **门槛与交付物**：核对每页“上线门槛”和“你会拿到什么”，确保实施团队能兑现

## 打印

- 桌面端右上角“打印 / PDF”导出
- 已做封面 / 封底和 A4 分页；每个模块页约 7 页，总览约 6 页
- 打印版会隐藏“上线门槛”条（屏幕版保留），避免分页出现孤行
- 导出前建议在浏览器预览一次，重点看封面、封底和表格分页
- 页脚在打印时隐藏，合同物料和免责声明放在封底

- 详细版：`../modules/*.html` 保留冲突规则、人机分层、全部能力清单，适合计划员 / IT / 实施评估
