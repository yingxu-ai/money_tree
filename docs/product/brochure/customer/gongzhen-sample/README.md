# 工诊 · 6 页 A4 样张

按施耐德 PMA 那本的叙事做的工诊客户版样张：**封面 → 痛点/成熟度 → 角色价值 → 怎么做到 → 案例 → 落地/联系**。

## 文件

- `index.html`：6 页 A4，可直接打开；右上角“打印 / PDF”
- `gongzhen-sample.pdf`：导出的 6 页 PDF
- `assets/`：来自本地 `http://localhost:5174` 的系统界面截图（2#压缩机 EQ-C02）

## 这版和之前客户版的区别

- 不再一页塞 8 个板块；一页只讲一个论点
- 用“响应式 → 预防性 → 状态监测 → 预测性 → 可靠性维修”的成熟度阶梯给客户定位
- 按一线 / 设备主管 / 高层三类人写价值，不按功能列
- 架构、频谱、特征表、整站热区都用系统界面，不用 CSS 示意图
- 案例按时间线讲：采样 → 诊断 → 处置 → 计划检修
- 数字全部来自系统：6.2 mm/s、2× 5.07/2.5、轴承 76%、RUL 3–9 天、72%、8h vs 2天1小时
- 最后一页落到“先选一类设备、接 5–10 个测点、一周数据验证”

## 对外使用前

1. **联系方式**：第 6 页姓名、手机、微信、邮箱、二维码
2. **品牌素材**：正式对外可替换 logo、字体、主色和页脚版权信息
3. **行业清单**：第 6 页行业按实际覆盖范围增删
4. **文案口径**：发布前按公司对外口径复核数字与案例表述

## 打印

- A4，6 页，已做封面/封底和分页
- 浏览器打印时建议勾选“背景图形”，否则封面深色底可能不打印
- 页面在屏幕上按 A4 比例显示，手机端自动改为单列
