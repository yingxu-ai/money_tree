智能排产（智排） · 产品介绍 · 2026-10

01 · 你是不是也这样

计划改一次，车间乱三天

多数工厂不缺一张甘特图（排产时间轴），缺的是一套能跟着车间改的计划。

急单

Excel 全表重排，改完才发现撞机

急单插进来，整张表重算；改到一半发现焊机被两个人同时占，现场才爆出来。

→ 先试排，看到影响再发布
两张皮

计划在办公室，报工在纸上

甘特图很漂亮，实际做到哪一步没人知道；偏差没人处理，计划永远是理想态。

→ 车间按天报工，偏差有人管
冲突

要么全红，要么全不管

同班多单本可以串行，被系统一刀切卡死；Excel 又发现不了抢机，最后退回口头调度。

→ 抢机才红，活太满才黄
02 · 用起来是什么样

建一次，每天改单，现场报工

不改变车间的说话方式：计划员排产，班组长调机台，班组报工，主管看风险。

STEP 01 · 一次

建基础资料

设备、人员与技能、工序与标准工时、班次。班次固定就建一次，不用天天维护。

计划员 / 实施协助
STEP 02 · 每天

排产、改单

订单进甘特图，拖拽调日期、班次、机台和责任人；急单先试排，看影响再发布。

计划员 / 班组长
STEP 03 · 每天

现场报工

开工 / 暂停 / 完工，日报加电子签名；计划和实际的偏差有人处理。

班组 / 主管
计划员 排产、插单、重排班组长 调机台、处理冲突班组 开工、完工、签字主管 看交期、负荷、风险
i

不用接设备也能先用。系统按计划和报工判断设备占用；以后接了工诊，再叠加真实运行状态。第一笔投入不用花在设备联网采集（IoT）上。

03 · 三个关键差异

抢机才红，活太满才黄

规则贴近老师傅常识，系统才有人用。

硬冲突 · 必须改超载 · 提醒，可继续
先试后发

改坏了，一键撤回

试排（先模拟一版，不马上生效）里随便改，影响预览看清哪张单会延、哪台机会撞；发布才生效，放弃就回到原样。

冲突分档

该红的红，该黄的黄

两个人抢一台机＝硬冲突，必须改；同一个人同班多单＝按串行算，超过班次才黄灯提醒，仍可保存。

计划落地

排到具体机台和人

周历回答谁上班，工序模板回答这类活能用哪些机，甘特最后定哪一台；不混在一张表里硬排。

试排影响清单 · 示意
受影响订单3 张
交期变化1 张延后
撞机1 处
可回退是

发布前就能看到后果；放弃则回到发布前，不用推倒重来。

04 · 一个具体场景

从“全表重排”到“会上就能定”

同样的急单，区别不在排得快，而在改之前就知道后果。

16:00

急单进来

客户加急，标记为加急优先级。

16:05

进入试排

按加急优先重排未完成工序，不动已执行的历史。

16:10

看影响

3 张单交期变化，1 台焊机撞机；换一台同类型焊机。

16:20

发布

班组长确认机台和责任人，发布；不满意可放弃回退。

以前Excel 全表重排，改完发现撞机，再改；计划发出去，晚上又变。
现在会上先看后果，确认再发布；改坏了撤回，不用推倒重来。

以上为示例场景，时间为示意；实际效果以试点数据为准。

05 · 适不适合你

先看订单、设备和基础资料

不是所有工厂都适合；先看订单结构、设备争用和主数据。

通常会比较适合

  • 品种多、批量小，插单和返工多
  • 三班倒或多班制，请假、替班频繁
  • 焊机、机加、注塑等关键设备经常抢用
  • 计划在办公室、报工在纸上，两张皮
  • 想先管交期和争用，不想先上设备联网

建议先别急

  • 单品种、大批量、节拍固定的流水线
  • 订单机台和交期完全由客户指定，自己不能调
  • 没有设备清单、工序和标准工时，也不打算整理
  • 只想解决“报工记录”，不需要排产
  • 期望“AI 全自动、人不用管”
上线门槛

至少要有：设备清单、工序 / 标准工时、当前在制订单。没有这三样，排出来也不可信。

不符合不代表永远不能用，但先从最痛的点小范围试点更稳。

06 · 怎么开始

先在一个车间，跑一周真实订单

不要先全厂铺开；用一个车间、5–10 个产品、一周真实订单，验证插单和交期。

试点三步

  1. 选一个车间 + 5–10 个产品订单结构、设备争用、交期压力最明显的那一组。
  2. 建资料 + 导入在制订单设备、人员、工序、班次；把当前在制订单和交期录进来。
  3. 跑一周真实订单试排、插单、发布、报工；复盘插单响应和交期风险。
部署云端开通（SaaS），或本地部署
终端计划用电脑；现场用车间电脑 / 平板
数据账号、组织、权限随平台
服务上线培训 + 使用答疑

试点前，你只需要准备这些

  • 设备清单：编号、名称、所属车间、班次
  • 人员名单：班组、技能、可上班次
  • 5–10 个典型产品：工序、标准工时、可用设备
  • 当前在制订单和近期交期
  • 现在的排产表（Excel 也行）

基础资料可以由实施协助整理；批量导入的格式和范围，试点前一起确认。

价

怎么报价：按上线范围和车间规模沟通；可以先小范围试点，再决定是否扩展。具体功能、交付范围与报价以合同为准。

07 · 常见问题

你可能还会问

试排会不会把正式计划搞乱？

不会。试排是独立沙箱，发布才生效；放弃就回到发布前。

没有标准工时能排吗？

可以先按历史工时估，但排产可信度会打折；试点时优先补 5–10 个典型产品。

和 ERP / MES 是什么关系？

可以单独用；BOM、库存、采购、财务留在 ERP / 进销存，智排管工单、工序、设备、人员和报工。

手机能报工吗？

当前建议用车间电脑或平板；手机端暂未适配。如果你们希望手机报工，试点时可以一起评估。

多久能上线、多少钱？

取决于基础资料和试点范围；按上线范围与车间规模沟通，先试点再决定。

我们厂小，值得上吗？

如果痛点是插单、撞机、交期，先一条线 / 一个车间试，投入可控；不合适会直接说。
