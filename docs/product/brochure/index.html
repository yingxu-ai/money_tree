01 · 为什么需要

制造企业不缺系统，缺跟着车间走的决策闭环

从交期到设备、从质量到规范，痛点往往不在「有没有软件」，而在决策链条是否对得上现场。

交期靠人脑、插单靠吼

计划一改全乱，争机抢人加班却仍延误。

设备坏了才知道

非计划停机、备件被动、产能承诺失信。

质检在事后、标准在纸上

批次风险后置，经验难以复制。

配方工艺靠老师傅

换人就波动，优化难沉淀、难复用。

操作规范难落地

培训成本高，同类失误反复发生。

03 · 六大能力域

可分可合，按痛点选模块

六大能力共用同一平台壳与组织权限，均可独立采购；合买强调数据对齐与业务闭环。

智排

智能排产模块

可售 · 单册

把交期、人、机、班次一次排清：插单可试、冲突可分、现场可报。

基础数据→ 工单管理→ 排产甘特→ 工序报工
  • 人 / 技能+设备池 / 甘特落机 三层清晰，周历管人、甘特管机
  • 冲突分档：抢机硬冲突 vs 同班串行超载告警，贴近车间习惯
  • 试排沙箱 + 多策略重排 + 影响预览，插单敢改、敢看后果再发布
  • 报工签字 + 偏差处置，计划到现场同体系闭环
  • 可单买：不依赖其他模块也能表达占用与空闲
维度常见做法智排
人机关系混在一张表分层清晰
冲突事后发现 / 一刀切硬冲突 / 超载分档
插单改死难回退试排 + 预览 + 发布
工诊

设备健康分析模块

可售 · 单册

先看清坏在哪，再看会不会坏，最后在安全边界内把设备用好。

采集配置→ 机队视图→ 分析诊断→ 预测 / 优化
  • 现状健康 vs 未来风险 同屏分口径，不揉成一个红黄绿
  • 单机路径：证据 → 对照 → 处置 → 预测 / 优化
  • 机队视角：部门范围、类型趋势、事件队列，再下钻单机
  • 运行优化带约束：异常未处理时阻断激进调参
  • 可单买：独立建设采集—诊断—预测—优化链路
维度常见做法工诊
输出告警列表证据链 + 处置
时间多为现状现状与未来分口径
优化少或无约束带状态约束调优
智检

工业质检模块

可售 · 单册

把质量从事后判废，前移到过程可检、结果可追溯、异常可闭环。

检验方案→ 过程 / 成品检→ 判定与处置→ 批次追溯
  • 支持过程检、成品检、抽样与全检策略，按工序 / 批次挂接工单
  • 不合格闭环：隔离、让步、返工、报废可配置，责任可追溯
  • 检验记录、影像 / 数据证据与质量报告一键归档
  • 质量看板：不良分布、逃逸风险、供应商 / 班组对比
  • 可单买；与智排合买时，质检结果驱动放行与返工重排
维度常见做法智检
时机事后抽检过程 + 成品闭环
追溯纸质 / 分散表批次证据一体
处置口头协商可配置闭环
智方

配方优化模块

可售 · 单册

在成本、质量与供应约束下，把配方从老师傅经验变成可复制、可审计的资产。

配方版本→ 约束建模→ 试验 / 优化→ 量产切换
  • 配方主数据与版本管理：草稿、试验、量产、冻结可区分
  • 目标与约束可配置（成本、性能、稳定性、关键原料可用性等）
  • 可解释优化建议：给出调整方向与预期影响，便于评审签核
  • 试验批结果回写，驱动下一轮配方迭代
  • 可单买；与智检 / 智艺合买时形成「方—检—艺」闭环
维度常见做法智方
沉淀个人经验版本化资产
优化试错靠感觉约束下可解释
切换口头通知签核后量产切换
智艺

工艺优化模块

可售 · 单册

盯住关键工序的工艺窗口与节拍稳定性，减少「同设备、不同人、不同结果」。

参数采集→ 黄金批次→ 窗口推荐→ 偏移预警
  • 关键工序工艺参数采集与对照，建立黄金批次基线
  • 工艺窗口推荐：在质量与节拍约束下给出可执行参数带
  • 过程偏移预警：偏离窗口及时提示，避免大批量不良
  • 与设备工况、质检结果联合分析，区分「机」与「艺」问题
  • 可单买；与智排合买时，节拍变化可反馈标准工时
维度常见做法智艺
标准口头传艺窗口 + 基线
波动事后复盘偏移即时预警
归因人机混谈可联合设备 / 质检
智规

操作流程规范模块

可售 · 单册

把 SOP 从墙上的文件，变成可执行、可培训、可检查、可追溯的现场动作。

规范编制→ 生效发布→ 现场执行→ 稽核改进
  • 覆盖开班、换型、点检、保养、安全等高频作业规范
  • 步骤级执行：关键点确认、拍照 / 签字、偏离记录
  • 版本生效与回收：现场只看见当前有效版本
  • 培训考核与执行合规分析，同类失误可定位到步骤
  • 可单买；与智排 / 工诊合买时，派工与点检动作绑定规范
维度常见做法智规
载体纸质 / PDF可执行流程
执行靠自觉步骤确认可追溯
改进难定位偏离到步骤

同一套平台，多种组合打法

模块边界清晰、编码与组织对齐——合买强调决策用同一套事实，而不是功能堆砌。

智排

计划占用与派工

  • 谁在哪班、占哪台机
  • 交期、冲突、负荷
  • 报工与偏差
+
工诊

健康、预测与优化

  • 关键机是否健康
  • 未来风险与 RUL
  • 约束下的运行建议
智排 × 工诊增量

敢排——高风险机避免仍被高负荷占用； 敢养——维修窗口对照交期与班次； 对齐——排产会与维修会用同一套设备事实。

智检 × 智排

质检结果驱动放行、返工工单与交期重排，质量不再游离在计划之外。

智方 × 智艺 × 智检

配方调整 → 工艺窗口 → 实测验证，经验沉淀为可复用闭环。

智规 × 任意模块

开班、换型、点检、检验动作与规范绑定，标准真正落到现场。

01

交期与设备

智排控交期人机争用；工诊管关键机健康与风险。

02

质量与工艺

智检前移质量；智方 / 智艺沉淀配方与工艺窗口。

03

现场规范

智规把 SOP 变成可执行动作，与派工 / 点检对齐。

05 · 组合方案

按痛点选包，降低决策门槛
