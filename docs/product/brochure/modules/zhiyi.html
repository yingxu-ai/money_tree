01 · 为什么需要智艺

工艺稳定，是交期与质量共同的底座

很多波动被归因于「人的手感」或「设备不行」，却缺少可对照的工艺窗口与基线。参数散落在机台、纸质工艺卡与个人习惯里：偏移发现晚，复盘难定位，标准工时也因此失真。

同设备不同结果

甲班合格乙班不良，节拍忽快忽慢，客户与计划都难预期。

窗口只在老师傅脑子里

新人调参靠模仿，工艺卡更新滞后。

偏移事后才知

大批量不良已发生，才去翻历史参数。

人机艺混谈

不知道是设备劣化、配方问题还是工艺跑偏，改进打错靶。

02 · 单买即可交付的价值

让工艺从「经验」变成「可监控的窗口」

有基线

黄金批次沉淀「怎样算做好」。

有窗口

推荐可执行参数带，兼顾质量与节拍。

有预警

偏离窗口即时提示，而不是事后复盘。

03 · 谁在用
角色典型动作
工艺工程师定义关键工序与关键参数；维护黄金批次；发布窗口；分析偏移原因；推动标准化。
调机 / 班组长按推荐窗口开机与调参；响应偏移预警；记录必要的人工确认。
质量将不良模式与窗口偏离关联；合买智检时闭环验证。
设备合买工诊时，与健康诊断联合判断「机还是艺」。
计划合买智排时，节拍变化反馈标准工时与产能。
04 · 能力闭环

采集 → 基线 → 窗口 → 监控预警 → 标准化回写

参数采集→ 黄金批次→ 窗口推荐→ 偏移预警→ 复盘与固化
  • 关键工序优先：先抓住对质量 / 交期影响最大的几道工序，而不是一次铺开全厂。
  • 窗口不是越窄越好：在质量与节拍约束下给出「可执行」参数带，现场才用得起来。
  • 优化结果可回写智规（标准化作业）与智排（标准工时），避免优化停在报告里。
05 · 黄金批次与基线

先回答：什么叫「这道工序做对了」

  • 选定质量好、节拍稳、可复现的批次作为黄金批次参照。
  • 沉淀关键参数轨迹与结果指标，形成对照基线。
  • 新班组、新机台、新配方切换后，可重新评估基线是否仍适用。
  • 基线变更需可追溯，避免「偷偷改标准」。
06 · 工艺窗口推荐

给现场的是参数带，不是一句「调好一点」

窗口要解决的问题

  • 温度 / 压力 / 速度 / 时间等关键量落在哪段更稳
  • 质量合格与节拍目标如何同时满足
  • 不同设备个体差异如何纳入（合买工诊时更有底）

对现场的输出形态

  • 推荐区间与中心值
  • 超出区间的风险说明
  • 与黄金批次的对照摘要
  • 可写入作业指导 / 智规步骤
07 · 偏移预警与联合归因

早发现，并且分得清是谁的问题

  • 过程参数持续偏离窗口 → 即时预警，避免堆出大批不良。
  • 与智检合买：不良模式是否与某参数偏移同步出现。
  • 与工诊合买：是工艺跑偏，还是轴承 / 温度控制等设备劣化。
  • 与智方合买：配方切换后窗口是否需要重标定。
08 · 典型业务场景
场景 A

注塑工序夜班不良升高

偏移预警显示保压/温度偏离窗口 → 班长按推荐带回中 → 智检复检合格率回升；同时工诊排除液压异常。

结果：当班可处置，归因不打架。
场景 B

新品导入，标准工时不准

黄金批次跑稳后，窗口与节拍数据反馈智排标准工时 → 计划不再按拍脑袋工时排。

结果：工艺优化直接变成交期可信度。
场景 C

换配方后老窗口失效

智方量产切换 → 智艺重评窗口 → 智规更新作业步骤 → 智检加密抽检一段时间。

结果：变更有配套，不是只换一张配方单。
09 · 差异对比
维度口头传艺静态工艺卡智艺
标准在人脑更新慢窗口 + 基线可维护
波动事后复盘难监控偏移即时预警
归因人机混谈缺数据可联合设备 / 质检
固化难发文易漏可回写规范与工时
10 · 适用自检
  • 关键工序对质量与节拍敏感，班组差异明显
  • 已有或可采集关键工艺参数
  • 希望减少对人的依赖，缩短新人上手周期
  • 需要把工艺稳定与设备健康、质检结果放在一起看
