工诊 可售

设备健康分析模块 — 先看清坏在哪，再看会不会坏，最后在安全边界内把设备用好。覆盖生产机台与动力公用设备（空压、泵、冷水机组等场景），把告警台升级为可解释的诊断与约束优化。

01 · 为什么需要工诊

工厂不缺测点，缺的是「证据 → 结论 → 动作」

SCADA 与告警台能告诉你「超限了」，却很难说清：是哪一类故障、证据是否一致、会不会继续恶化、该先修还是先调参、备件与工单怎么准备。BI 看板好看，但往往事后统计，撑不起当班决策。

工诊把设备能力做成一条完整链路：采集配置 → 机队总览 → 分析诊断 → 单机证据链 → 未来风险 → 带约束的运行优化。

坏了才知道

非计划停机打乱交期，备件被动采购，产能承诺失信。

需要：未来风险与 RUL 分口径可见。

告警噪声大

红黄绿刷屏，值班人员疲劳；真正危险被淹没。

需要：结论 + 证据 + 原因概率，而不是堆测点。

优化建议不敢用

节能/提负荷建议与报警并存，怕越调越糟。

需要：异常未关闭时阻断激进调优。

机队看不清

多车间多类型设备，列表扁平，主管无法先圈范围再下钻。

需要：与组织树同源的机队视角。

02 · 单买即可交付的价值

不依赖智排，也能独立建成健康闭环

可解释

对照分析给出结论、证据、原因概率与处置步骤。

可分口径

现状健康与未来风险同屏，但不混读成一个灯。

可约束优化

先处置异常，再谈节能与负荷，避免假优化。

与工厂组织树同源过滤，适合多车间 / 多工厂按部门范围看机队，而不是静态演示列表。采集侧支持数据源与测点分类（PLC 工况、电气、环境等）及设备—测点绑定。

03 · 谁在用

从采集配置到当班处置，角色清晰

角色典型动作
设备 / 维修工程师诊断总览筛选异常与事件；进入单机对照分析；按处置步骤闭环；查看预案与备件提示。
能源 / 运行岗在设备状态允许时查看运行优化场景（节能、平衡、高负荷、长寿命）；检查约束是否满足。
车间 / 设备主管按部门与类型看机队 KPI、健康分布与未来风险；设备对比与趋势；安排维修窗口优先级。
信息化 / 采集配置维护数据源、测点分类与设备绑定；按组织树控制可见范围。
04 · 能力闭环

采集 → 机队 → 诊断 → 预测 / 优化

采集配置→ 设备列表 / 机队→ 分析诊断总览→ 单机深潜→ 预测 / 优化
  • 采集配置：数据源与测点分类；设备—测点绑定；部门树筛选。
  • 设备列表：KPI、检索与状态筛选；机队图表（运行状态趋势、类型趋势、组织分布等）。
  • 分析诊断总览：按部门 / 类型 / 运行或在线状态 / 时间口径（本班、24h、7d 等）聚合；事件队列。
  • 单机：总览、对照分析、未来、指标预测、健康示意、运行优化、对比入口。
05 · 机队视角

先圈范围，再下钻 —— 主管与工程师共用一张图

  • KPI：总数、在线、异常与关注、未来风险、待处理事件。
  • 现状健康分布与 未来风险 同屏展示、分口径阅读——避免揉成一个「红黄绿」糊弄决策。
  • 趋势、类型分布、组织分布等图表服务「哪里先看」；事件流服务「今天先处理什么」。
  • 设备对比：多设备、多周期横向对照（含状态泳道），适合同型机或跨班组对比。
06 · 单机深潜（证据链）

输出不是告警列表，而是可开会的结论包

对照分析

  • 结论与证据链
  • 原因概率与恶化情景
  • 趋势、测点带、多源一致
  • 同业 / 同型对比
  • 处置步骤可执行

未来与示意

  • 多时间窗风险（如 24h / 72h / 7d）
  • RUL 及置信；故障类型概率
  • 预案 / 备件 / 工单提示
  • 离线则预测暂停，避免假精确
  • 健康示意热区，便于沟通培训
07 · 运行优化（带约束）

先安全与稳定，再谈节能与负荷

优化场景包括节能、平衡、高负荷、长寿命等，并检查设备当前状态约束。报警未关闭时可阻断激进调优——这是工诊与「只出建议不管后果」的工具的关键差异。

08 · 典型业务场景

从当班异常到维修计划

场景 A

空压站异响 / 振动异常，值班不知是否停机

总览圈定动力车间异常设备 → 进入单机对照分析，查看证据与原因概率 → 按处置步骤先降负荷或安排点检 → 同步看 72h 风险是否上升。

结果：当班有结论、有步骤，而不是只盯着一条报警。
场景 B

同型注塑机对比：哪台该优先保养

设备对比选同型机与周期 → 健康与风险分口径排序 → 结合 RUL / 事件积压安排保养窗口。

结果：保养从「轮流做」变成「风险优先」。
场景 C

想节能调参，但设备仍有未关闭报警

优化面板检查约束 → 激进调优被阻断 → 先关闭/处置报警事件 → 再给出节能或平衡建议。

结果：避免「带病优化」造成二次故障。
09 · 与常见做法的差异

从「看见超限」到「能决策」

维度纯 SCADA / 告警台通用 BI 看板工诊
输出阈值超限指标好看证据 → 对照 → 处置
时间多为现状事后统计现状与未来分口径
优化少或无约束难落地带状态约束调优
组织点位扁平报表割裂机队范围 + 单机钻取
10 · 适用企业自检
  • 关键设备停机损失高，备件与维修偏被动
  • 动力站与产线设备并存，需要机队级视野
  • 已有或计划接入 PLC / 电气 / 环境等测点
  • 希望从「看报警」升级到「可解释诊断 + 可约束优化」
  • 多车间 / 多工厂，需要按组织范围授权查看
11 · 合买协同

与智排对齐编码，不把算法塞进甘特

工诊 × 智排：计划机台 ↔ 现场机台编码映射；敢排敢养，交期会议与维修会议同一套事实。

工诊 × 智艺：工艺偏移 vs 设备劣化联合归因，少误判。

工诊 × 智规：点检 / 保养规范与健康事件闭环。
